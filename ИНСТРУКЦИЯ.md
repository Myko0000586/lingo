# Lingo — как запустить и установить на iPhone

Приложение состоит из двух частей:
1. **Само приложение** (папка с файлами) — выкладывается на GitHub Pages, открывается на iPhone.
2. **ИИ-учитель** (`worker.js`) — отдельный бесплатный сервер на Cloudflare, который проверяет письмо. Нужен только для вкладки «Письмо».

Можно сделать только часть 1 — всё, кроме проверки письма, заработает сразу.

---

## Часть 1. Опубликовать приложение (GitHub Pages)

Загружать нужно **6 файлов** (папку `.claude` и `worker.js` НЕ загружай):
`index.html`, `app.js`, `data.js`, `manifest.json`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`

1. Зайди на **github.com** (ты уже залогинен).
2. Справа вверху **＋ → New repository**.
3. Имя: `lingo` → **Public** → **Create repository**.
4. На странице репозитория: **Add file → Upload files**.
5. Перетащи 6 файлов из папки на рабочем столе `new dualingo`.
6. Внизу — **Commit changes**.
7. Вкладка **Settings → Pages** → раздел **Branch**: выбери **main** и **/ (root)** → **Save**.
8. Через 1–2 минуты вверху появится ссылка вида
   `https://ТВОЙ_ЛОГИН.github.io/lingo/`

### Установить на iPhone
1. Открой эту ссылку в **Safari** на айфоне.
2. Кнопка **«Поделиться»** (квадрат со стрелкой) → **«На экран Домой»**.
3. Готово — появится иконка как у обычного приложения. То же самое можно сделать на телефоне жены.

## Часть 2. Подключить ИИ-учителя (проверка письма)

### Шаг А. Получить ключ Anthropic
1. Зайди на **console.anthropic.com**, зарегистрируйся.
2. **Billing** → пополни баланс (хватит и небольшой суммы — одна проверка стоит доли цента).
3. **API Keys → Create Key** → скопируй ключ (он показывается один раз!). Выглядит как `sk-ant-...`

### Шаг Б. Создать сервер на Cloudflare (бесплатно)
1. Зайди на **dash.cloudflare.com**, зарегистрируйся.
2. Слева **Workers & Pages → Create → Create Worker**.
3. Назови, например, `lingo-teacher` → **Deploy** (создастся заготовка).
4. Нажми **Edit code**. Удали весь код в редакторе и вставь содержимое файла **`worker.js`** (из папки на рабочем столе). → **Deploy**.
5. Вернись к Worker → **Settings → Variables and Secrets**:
   - Добавь **Secret**: имя `ANTHROPIC_API_KEY`, значение — твой ключ `sk-ant-...`
   - (необязательно) переменная `MODEL` — оставь пустым, если не уверен.
   - **Save / Deploy**.
6. Скопируй адрес Worker — он вида `https://lingo-teacher.ТВОЙ.workers.dev`

### Шаг В. Вписать адрес в приложение
1. Открой приложение → вкладка **Профиль ⚙️** → раздел **«ИИ-учитель»**.
2. Вставь адрес Worker → **Сохранить адрес** → **Проверить связь**.
3. Если «✅ Учитель отвечает» — всё готово. Теперь на вкладке **Письмо** жена пишет предложения, а учитель их проверяет и комментирует.

---

## Как обновлять приложение потом
Если я добавлю новые уроки/слова — просто заново загрузи изменённые файлы в репозиторий (Add file → Upload files → Commit). На iPhone приложение обновится само (можно закрыть и открыть заново).

## Если что-то не работает
- «Письмо» пишет, что учитель не подключён → проверь адрес в Профиле (Часть 2, Шаг В).
- «Нет связи» → проверь, что в Worker задан `ANTHROPIC_API_KEY` и на балансе Anthropic есть средства.
- Просто пришли мне, что именно не получается — помогу.
